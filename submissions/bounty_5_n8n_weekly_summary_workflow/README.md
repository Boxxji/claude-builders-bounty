## Setup in 4 Steps
1. Open n8n and click **Import from File** -> select `n8n_weekly_claude_dev_summary.json`.
2. Set environment variables `ANTHROPIC_API_KEY` and `SLACK_OR_DISCORD_WEBHOOK_URL`.
3. Edit the `Configurable Variables` node (`GITHUB_REPO`, `SUMMARY_LANGUAGE` = `EN` or `FR`).
4. Activate the workflow (triggers every Friday at 17:00 via cron `0 17 * * 5`).
